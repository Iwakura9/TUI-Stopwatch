# TUI-Stopwatch
Aplicativo simples de cronômetro TUI, feito para testar e aprender a biblioteca Textual.

### Funcionalidades
- Cronômetro  :)
- Múltiplos cronômetros simultâneos (quantos quiser)
- Vários temas escuros e claros
- Screenshot nativo
- Aceita mouse

## Como instalar e rodar
#### Pré-requisitos
- Python 3.11 ou superior
- Git

##### Linux/MacOS:
```bash
git clone https://github.com/Iwakura9/TUI-Stopwatch
cd TUI-Stopwatch
python -m venv .venv
source .venv/bin/activate
pip install textual
python stopwatch.py
```

##### Windows:
```bash
git clone https://github.com/Iwakura9/TUI-Stopwatch
cd TUI-Stopwatch
python -m venv .venv
source .venv/Scripts/Activate.ps1
pip install textual
python stopwatch.py
```
